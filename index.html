Copias de seguridad

Guarda una copia en un lugar seguro. Los datos de este sistema son locales y no se sincronizan automáticamente entre el computador y el celular.

Para pasar los datos al otro dispositivo, exporta la copia y transfiere el archivo por USB u otro medio seguro; luego impórtalo allí. Evita restaurar una copia antigua si tienes ventas nuevas que deseas conservar.

Limitaciones de esta versión

  • Necesita abrirse en el mismo navegador y dispositivo para ver los datos guardados.
  • No es facturación electrónica autorizada por la DIAN; el recibo es un comprobante simple.
  • Para impresión de recibos, usa la función de imprimir del navegador.
  • El lector de códigos debe actuar como teclado. La cámara del celular no está integrada en esta versión.
